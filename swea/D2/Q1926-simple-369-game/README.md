# Q1926 간단한 369게임

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 반복 계산

## 문제 설명
숫자 1부터 차례대로 말하되, "3", "6", "9"가 들어가 있는 수는 말하지 않음.
"3", "6", "9"가 들어가 있는 수는 말하지 않는 대신, 박수.
해당 숫자가 들어간 개수만큼 박수 치기.
ex) 35 -> 1번, 36 -> 2번

입력으로 정수 N이 주어졌을 때, 1~N 까지의 숫자를 규칙에 맞게 출력.

박수 치는 부분은 숫자 대신 박수 횟수에 맞게 "-" 출력.
ex) 박수 한 번 -> -  박수 두 번 -> -- (- - 아님.)

### 제약조건
- N은 10 이상 1,000 이하의 정수 (10 <= N <= 1,000)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 10 | 1 2 - 4 5 - 7 8 - 10 |
