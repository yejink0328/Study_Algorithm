## 문제 설명
패턴에서 반복되는 부분을 마디라고 부른다.
문자열을 입력 받아 마디의 길이를 출력.

### 제약조건
- 각 문자열의 길이는 30. 마디의 최대 길이는 10.

### 입출력 예
| 입력 | 출력 |
|---|---|
| KOREAKOREAKOREAKOREAKOREAKOREA | #1 5 |
| SAMSUNGSAMSUNGSAMSUNGSAMSUNGSA | #2 7 |
| GALAXYGALAXYGALAXYGALAXYGALAXY | #3 6 |
