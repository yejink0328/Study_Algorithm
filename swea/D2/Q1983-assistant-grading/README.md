# Q1983 조교의 성적 매기기

- 플랫폼: SWEA
- 난이도: D2
- 분류: 완전 탐색

## 문제 설명
학점은 상대평가로 주어지는데, 총 10개의 평점이 존재.

평점 : A+ A0 A- B+ B0 B- C+ C0 C- D0

학점은 학생들이 응시한 중간/기말고사 점수 결과 및 과제 점수 반영.

총점 = 중간고사(35%) + 기말고사(45%) + 과제(20%)

10개의 평점을 총점이 높은 순서대로 부여.
각각의 평점은 같은 비율로 부여 가능.

ex) N명의 학생이 있을 경우 N/10 명의 학생들에게 동일한 평점을 부여

입력으로 각각의 학생들의 중간, 기말, 과제 점수가 주어지고,
학점을 알고싶은 K 번째 학생의 번호가 주어졌을 때,
K 번째 학생의 학점을 출력


### 제약조건
1. N은 항상 10의 배수이며, 10 이상 100 이하의 정수 (10 <= N <= 100)
2. K는 1 이상 N 이하의 정수 (1 <= K <= N)
3. K 번째 학생의 총점과 다른 학생의 총점이 동일한 경우는 입력으로 주어지지 않음
