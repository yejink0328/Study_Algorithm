# Q2005 파스칼의 삼각형

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 반복 계산

## 문제 설명
크기가 N인 파스칼의 삼각형을 만든다.

파스칼의 삼각형은 아래와 같은 규칙을 따른다.
1. 첫 번째 줄은 항상 숫자 1
2. 두 번째 줄부터 각 숫자들은 자신의 왼쪽과 오른쪽 위의 숫자의 합으로 구성

ex)
N=4

    1
   1 1
  1 2 1
 1 3 3 1

 N을 입력 받아 크기 N인 파스칼의 삼각형을 출력.

### 제약조건
- 파스칼의 삼각형의 크기 N은 1 이상 10 이하의 정수 (1 <= N <= 10)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 4 | #1
1
1 1
1 2 1
1 3 3 1 |
