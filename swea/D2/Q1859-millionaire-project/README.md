# Q1859 백만 장자 프로젝트

- 플랫폼: SWEA
- 난이도: D2
- 분류: 구간 최대값 계산

## 문제 설명
최대한의 이득은 얼마인지 출력.

1. 연속된 N일 동안 물건의 매매가를 알고 있음.
2. 하루에 최대 1만큼 구입 가능.
3. 판매는 제한 없이 가능.

ex) 3일 동안 매매가가 1, 2, 3 이라면 처음 두 날에 원료를 구매하여 마지막 날에 팔면 3의 이익을 얻을 수 있음.


### 제약조건
- 첫째 줄 : 연속된 날의 수 N (2 <= N <= 1,000,000)
- 둘째 줄 : 각 날의 매매가 N개의 자연수 (10,000 이하)


### 입출력 예
| 입력 | 출력 |
|---|---|
| 3
10 7 6 | #1 0 |
| 3
3 5 9 | #2 10 |
| 5
1 1 3 1 2 | #3 5 |
