# Q1984 중간 평균값 구하기

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 반복 계산

## 문제 설명
10개의 수를 입력 받아, 최대수와 최소수를 제외한 나머지의 평균값을 출력
(소수점 첫째 자리에서 반올림한 정수 출력)

### 제약조건
- 각 수는 0 이상 10000 이하의 정수 (10 <= N <= 10000)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 3 17 1 39 8 41 2 32 99 2 | #1 18 |
| 22 8 5 123 7 2 63 7 3 46 | #2 20 |
| 6 63 2 3 58 76 21 33 8 1 | #3 24 |
