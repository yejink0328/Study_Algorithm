# Q10760 우주선착륙2

- 플랫폼: SWEA
- 난이도: D2
- 분류: 완전 탐색

## 문제 설명
착륙 지점을 중심으로 주변 8개 구역을 대상, 착륙지점보다 높이가 낮은 구역의 사진을 촬영 가능.

예비 후보지는 8개의 방향 중 사진을 찍을 수 있는 방향이 4방향 이상인 지점.

측정한 주변 높이 정보가 주어질 때, 예비 후보지의 수를 출력.
주변에 높이 정보가 없는 영역이 포함되어 있어도, 알려진 영역의 높이만 조건을 충족하면 후보지에 포함.

1 2 3
4 2 4
3 2 1
-> 이 지형은 착륙지 높이(2)보다 낮은 지역이 2곳 밖에 없어서 후보지가 될 수 없다.

1 2 3
4 3 5
3 2 1
-> 이 지형은 착륙지 높이(3)보다 낮은 지역이 총 4곳이므로 후보지에 포함된다.


### 제약조건
- 구역의 크기 N, M, 높이 정보 Aij
- 3 <= N, M <= 100, 0 <= Aij < 10
