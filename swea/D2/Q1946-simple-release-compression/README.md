## 문제 설명
원본 : 너비가 10인 여러 줄의 문자열.
마지막 줄은 제외하고 빈 공간 없이 왼쪽부터 채움.

압축 : 알파벳 연속된 개수 쌍으로 나열.

압축된 문서를 입력받아 원본 문서를 출력.

### 제약조건
- 압축된 문서의 알파벳과 숫자 쌍의 개수 N은1이상 10이하의 정수이다. (1 ≤ N ≤ 10)
- 주어지는 알파벳 Ci는 A~Z의 대문자이다. (i는 줄의 번호로 1~N까지의 수)
- 알파벳의 연속된 개수로 주어지는 수 Ki는 1이상 20이하의 정수이다. (1 ≤ Ki ≤ 20, i는 줄의 번호로 1~N까지의 수)
- 원본 문서의 너비는 10으로 고정이다.

### 입출력 예
| 입력 | 출력 |
|---|---|
| A 10
  B 7
  C 5 
 | AAAAAAAAAA
BBBBBBBCCC
CC |
