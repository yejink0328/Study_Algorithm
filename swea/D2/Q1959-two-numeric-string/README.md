# Q1959 두 개의 숫자열

- 플랫폼: SWEA
- 난이도: D2
- 분류: 반복 계산 후 비교 출력

## 문제 설명
N 개의 숫자로 구성된 숫자열 Ai (i=1~N)와 M개의 숫자로 구성된 숫자열 Bj(j=1~M).

Ai나 Bj를 자유롭게 움직여서 숫자들이 서로 마주보는 위치를 변경 가능.
(단, 더 긴 쪽의 양끝을 벗어나서는 안 됨)

서로 마주보는 숫자들을 곱한 뒤 모두 더할 때 최댓값을 출력.

ex) N=3인 Ai와 M=5인 Bj의 경우
    Ai = {1, 5, 3}
    Bj = {3, 6, -7, 5, 4}

          {1, 5, 3}
    {3, 6,-7, 5, 4}  --> 이 때 30이 최댓값.

### 제약조건
- N과 M은 3 이상 20 이하

### 입출력 예
| 입력 | 출력 |
|---|---|
| 3 5
1 5 3
3 6 -7 5 4 
 | #1 30 |
 | 7 6
6 0 5 5 -1 1 6
-4 1 8 7 -9 3 
 | #2 63 |
