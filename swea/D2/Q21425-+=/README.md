# Q21425 +=

- 플랫폼: SWEA
- 난이도: D2
- 분류: 반복 계산

## 문제 설명
현재 x에 저장된 값은 A, y에 저장된 값은 B.
"x += y" 또는 "y += x" 연산을 원하는 순서대로 원하는 만큼 수행.
x나 y 둘 중 하나 이상에 저장된 값이 N 초과가 되도록.
연산을 합쳐서 최소 몇 번 수행해야 하는지 출력.


### 제약조건
- 테스트 케이스는 한 개의 줄로 이루어짐.
- 각 줄에는 세 개의 정수 A, B, N (1 <= A, B <= N <= 10^9) 이 하나의 공백을 사이에 두고 주어짐.


### 입출력 예
| 입력 | 출력 |
|---|---|
| 1 2 2 | 1 |
| 1 2 3 | 2 |
| 1 2 4 | 2 |
| 1 2 5 | 3 |
| 10 7 1293 | 11 |
