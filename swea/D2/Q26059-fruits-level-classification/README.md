# Q26059 과일 등급 분류

- 플랫폼: SWEA
- 난이도: D2
- 분류: 완전 탐색

## 문제 설명
과일 N개를 무게에 따라 상, 중, 하 세 등급으로 분류.
각 과일은 하나의 정수 무게를 가짐. 두 개의 기준값 K1, K2 (K1 < K2, 실수)를 정하여 다음 규칙에 따라 등급 매김.

상 : 무게가 K2보다 큰 과일
중 : 무게가 K1 이상 K2 미만인 과일
하 : 무게가 K1 미만인 과일

이때, 세 등급 모두 과일 수가 주어진 최소 개수 lo 이상, 최대 개수 hi 이하.

K1과 K2를 적절히 설정하여 위 조건을 만족시킬 수 있는 경우,
가장 많은 과일이 속한 등급과 가장 적은 과일이 속한 등급의 개수 차이가 최소가 되도록.
그 차이의 최솟값을 출력.

조건을 만족하는 분류 방법이 없다면 -1 출력.

ex) test_case
1. 무게를 정렬하면 [1, 3, 4, 5, 5] 
K1 = 2.5, K2 = 4.5 로 설정하면 하등급 = {1}, 중등급 = {3, 4}, 상등급 = {5, 5}
개수는 {1, 2, 2}
모든 등급의 과일 수가 [1, 4] 범위 안에 있고, 최대(2) - 최소(1) = 1이 최솟값

2. 무게를 정렬하면 [1, 1, 2, 2, 4, 4]
K1 = 1.5, K2 = 3 으로 설정하면 하등급 = {1, 1}, 중등급 = {2, 2}, 상등급 = {4, 4}
개수가 (2, 2, 2)
최대 개수 - 최소 개수 = 0

3. 모든 무게가 10으로 동일. 세 등급으로 나눌 수 없음. -> -1


### 제약조건
- 1 ≤ T (테스트 케이스 수) ≤ 50
- 3 ≤ N ≤ 1,000
- 1 ≤ lo ≤ hi ≤ N
- 각 과일의 무게는 1 이상 10,000 이하의 정수


### 입출력 예
| 입력 | 출력 |
|---|---|
| 5 1 4
3 1 4 5 5  | #1 1 |
| 6 2 2
1 1 2 2 4 4  | #2 0 |
| 4 2 2
10 10 10 10  | #3 -1 |
| 5 1 3
1 1 1 2 5  | #4 2 |
