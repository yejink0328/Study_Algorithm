# Q1284 수도 요금 경쟁

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 계산

## 문제 설명
사용량이 W일 때, 더 적은 요금 출력.
A사 : 1L 당 P원
B사 : 기본요금 Q원, R 리터 기준 이하일 경우 기본요금/초과 시 리터 당 S원

### 제약조건
- P, Q, R, S, W (1 <= P, Q, R, S, W <= 10000, 자연수)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 9 100 20 3 10 | #1 90 |
| 8 300 100 10 250 | #2 1800 |
