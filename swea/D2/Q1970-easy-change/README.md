# Q1970 쉬운 거스름돈

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 반복 계산

## 문제 설명
우리나라 화폐 '원'은 금액이 높은 돈을 우선적으로 계산할 때 돈의 개수가 가장 최소.

돈의 종류 (원)
50,000
10,000
5,000
1,000
500
100
50
10

거스름돈 N이 입력되면 돈의 최소 개수로 거슬러 주기 위해 각 종류의 돈이 몇 개씩 필요한지 출력.

### 제약조건
- N은 10 이상 1,000,000 이하의 정수 (10 <= N <= 1,000,000)
- N의 마지막 자릿수는 항상 0. (ex. 32850)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 32850 | #1
0 3 0 2 1 3 1 0 |
| 160 | #2
0 0 0 0 0 1 1 1 |
