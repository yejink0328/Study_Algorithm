# Q1986 지그재그 숫자

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 계산

## 문제 설명
1부터 N까지의 숫자에서 홀수는 더하고 짝수는 뺐을 때 최종 누적된 값 출력

ex)
N이 5일 경우,
1 – 2 + 3 – 4 + 5 = 3

N이 6일 경우,
1 – 2 + 3 – 4 + 5 – 6 = -3

### 제약조건
- N은 1 이상 10 이하 정수 (1 <= N <= 10)

### 입출력 예
| 입력 | 출력 |
|---|---|
| 5 | #1 3 |
| 6 | #2 -3 |
