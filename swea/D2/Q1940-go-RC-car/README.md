# Q1940 가랏! RC카!

- 플랫폼: SWEA
- 난이도: D2
- 분류: 단순 반복 계산

## 문제 설명
0 : 유지
1 : 가속 + 가속도
2 : 감속 + 가속도

가속도의 단위는 m/s^2. 모두 양의 정수.
입력으로 주어진 N개의 command 모두 수행 시 N초 동안 이동한 거리 계산
RC카의 초기 속도는 0 m/s

### 제약조건
- N (2 <= N <= 30, 정수)
- 가속도의 값은 1 m/s^2 or 2 m/s^2
- 현재 속도보다 감속할 속도가 더 클 경우, 속도는 0 m/s

### 입출력 예
| 입력 | 출력 |
|---|---|
| 2
1 2
2 1 | #1 3 |
| 3
1 1
0
1 1 | #2 4 |
