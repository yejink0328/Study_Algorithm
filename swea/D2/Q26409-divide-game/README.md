# Q26409 나눗셈 게임

- 플랫폼: SWEA
- 난이도: D2
- 분류: 완전 탐색

## 문제 설명
N개의 자연수가 있는 카드 배열 A[1], A[2], ... , A[N]이 주어진다.
1부터 N까지에서 그 중 모든 가능한 서로 다른 순서쌍 (i, j)에 대해서 A[i]를 A[j]로 나눈 나머지를 모두 더한 값을 구하라.

ex) 주어진 카드 배열이 아래와 같다.
3     7     5    8
A[1] A[2] A[3]  A[4]

(i, j) = (1, 2)인 경우 : 3 % 7 = 3
(i, j) = (2, 3)인 경우 : 7 % 5 = 2

이러한 모든 경우의 나머지의 합은 37.


### 제약조건
- 카드의 원소 개수 N은 최소 3, 최대 100. (3 <= N <= 100)
- 카드의 원소 각각은 1 이상 120 이하의 자연수.


### 입출력 예
| 입력 | 출력 |
|---|---|
| 3
3 5 3  | #1 10 |
| 4
3 7 5 8  | #2 37 |
