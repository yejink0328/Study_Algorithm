## 문제 설명
두 개의 자연수를 입력받아 사칙연산을 수행

### 제약조건
- 두 개의 자연수 a, b는 1부터 9까지의 자연수 (1 ≤ a, b ≤ 9)
- 사칙연산 + , - , * , / 순서로 연산결과 출력.
- 나누기 연산 결과에서 소수점 이하의 숫자는 버림.

### 입출력 예
| 입력 | 출력 |
|---|---|
| 8 3 | 11
5
