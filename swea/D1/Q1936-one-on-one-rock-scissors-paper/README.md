## 시도별 메모

### solution1 — (단순 계산) (AC)
- 날짜: 2026-08-06
- 접근: A가 B에게 이기는 경우
    -> B가 1(가위)이면 A는 2(바위),
            2(바위)이면 A는 3(보), 
            3(보)이면 A는 1(가위)
    -> 3%(B의 경우) == A이면 된다.
- 결과 / 실패 원인: AC
