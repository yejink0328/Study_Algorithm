# Q2072 홀수만 더하기

- 플랫폼: SWEA
- 난이도: D1
- 분류: 단순 반복

## 문제 설명
10개의 수를 입력 받아, 그 중에서 홀수만 더한 값을 출력

### 제약조건
- 각 수는 0 이상 10000 이하 정수

### 입출력 예
| 입력 | 출력 |
|---|---|
| 3 17 1 39 8 41 2 32 99 2 | #1 200 |
| 22 8 5 123 7 2 63 7 3 46 | #2 208 |
| 6 63 2 3 58 76 21 33 8 1 | #3 121 |

|---|---|---|---|---|---|
