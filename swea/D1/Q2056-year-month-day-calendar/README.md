# Q2056 연월일 달력

- 플랫폼: SWEA
- 난이도: D1
- 분류: 단순 반복 + 조건문

## 문제 설명
연월일 순으로 구성된 8자리의 날짜가 입력
ex) 22220228 -> 2222/02/28

해당 날짜의 유효성 판단
    - 유효하다면 : "YYYY/MM/DD" 형식으로 출력
    - 유효하지 않으면 : -1 출력

월 : 1~12 사이의 값
일 : 1~각각의 달에 해당하는 날짜까지의 값

1월, 3월, 5월, 7월, 8월, 10월, 12월 : 31일까지
2월 : 28일까지(윤년은 고려하지 않음)
4월, 6월, 9월, 11월 : 30일까지
