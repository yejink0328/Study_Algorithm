## 문제 설명

### 제약조건
- 배열의 크기는 100 X 100으로 동일
- 각 행의 합은 integer 범위를 넘어가지 않는다.
- 동일한 최댓값이 있을 경우, 하나의 값만 출력


### 입출력 예
| 입력 | 출력 |
