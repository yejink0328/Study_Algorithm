# Q5642 [Professional] 합

- 플랫폼: SWEA
- 난이도: D3
- 분류: 단순 계산

## 문제 설명
N개의 정수가 입력으로 주어진다.
이때 연속하여 몇 개의 정수를 골라 합을 구할 수 있다.

예를 들어, 1 3 -8 18 -8 이 있다고 하자.
그럼 2번부터 4번까지의 수를 골라 합을 구하면, 3+(-8)+18 = 13이다. 

이렇게 연속해서 정수를 골라 합을 구할 때, 그 합의 최대가 몇인지 구하는 프로그램을 작성하세요.


### 제약조건
- 3 ≤ N ≤ 100,000
- 절대값이 1000이하의 정수 N개


### 입출력 예
| 입력 | 출력 |
|---|---|
| 5
1 3 -8 18 -8 | #1 18 |

## 시도별 메모

### solution1 — (단순 계산) (TLE)
- 날짜: 2026-09-17
- 접근: 누적합을 구한 후 이중 for문의 인덱스 조절 (j=i부터 시작, nums[j]-nums[j-1]로 값을 구하기) 로 모든 가능한 경우의 수를 찾아 비교.
    
- 결과 / 실패 원인: TLE /
    이중for문의 시간복잡도 n^2가 n이 커질수록 기하급수적으로 늘어나는 구조라, N이 큰 테스트 케이스에서 TLE 난 것 같다.
